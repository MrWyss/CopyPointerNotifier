## Product features

Short summaries of the product's key features (displayed as a bulleted list;
up to 20 features).

- Shows an instant indicator near your pointer every time you copy
- Detects text, rich text, images, files, and other clipboard formats
- Create ordered clipboard-format rules with custom indicator glyphs
- Capture, test, reorder, disable, and edit rules from the settings app
- Customize position, size, color, animation, and duration
- Back up and restore your settings, and optionally start with Windows
- Lightweight, private, offline tray app that never reads clipboard contents
